Why bother with a demo at all?

Most "AI coding agent on your phone" apps have a chicken-and-egg problem: to find out if the app is any good, you first have to install opencode, run a server, get an API key, and wire up a network tunnel — 10 to 15 minutes of setup before you've seen a single screen. That's a lot to ask before someone even knows if they want the thing.

OpenCode Mobile's demo mode removes that barrier entirely. It's a scripted, fully offline session baked into the app that exercises the same message bubbles, tool call cards, diff viewer, and permission prompts a real session uses — so you see exactly what driving a real AI coding agent from your phone feels like, before you touch a terminal.

What the demo walkthrough shows

The demo replays the same fixed scenario every time — a small, realistic Android bug fix:

  1. A bug report "The login button doesn't respond on Android when the keyboard is open — can you fix it?"
  2. Visible reasoning The agent explains its hypothesis: the scroll view is likely swallowing the first tap instead of forwarding it to the button.
  3. A file search tool call A grep call locates the relevant handler in LoginButton.tsx, rendered in the same tool call card real sessions use.
  4. An inline diff The agent proposes adding keyboardShouldPersistTaps="handled" to the scroll view — shown in the app's real side-by-side diff viewer.
  5. A permission prompt The agent asks to run npm test -- LoginButton before finishing. Tap Allow or Deny — the demo shows a different, accurate follow-up for each choice.
Honesty check: this is not a live AI model answering your questions. It is a fixed, hardcoded scenario that runs entirely offline — the point is to show you the actual screens and interactions (streaming bubbles, diffs, tool calls, permission prompts), not to let you chat freely. For that, you connect a real opencode server afterward.

How to try it

Three taps, no account

  1. Install OpenCode Mobile from F-Droid or a direct APK — no sign-up required.
  2. Open the app. On the first-run empty state, tap Try a Demo.
  3. Watch the scripted session play out, then tap Allow or Deny on the permission prompt to see how the agent responds either way.

That's the whole thing — no server URL, no password, no API key, and it works in airplane mode since nothing leaves the device.

After the demo: connect a real server

Once you've seen the interface, the natural next step is pointing the app at a real opencode server so you can actually chat with a live AI model (Claude, GPT, Gemini, or a local model) about your own codebase.

Bring your own server

On any machine with Node.js: 

npm install -g opencode-ai
OPENCODE_SERVER_PASSWORD=yourpassword opencode serve --hostname 0.0.0.0 --port 4096

Then in the app, tap Add Connection, enter your server's URL and password (over the same Wi-Fi, or via Tailscale for remote access) — and you're driving a real agent instead of the scripted one. The full setup guide walks through every step.

Frequently asked questions

Can I try OpenCode Mobile without setting up a server?

Yes. Install the app and tap "Try a Demo" from the empty state. It plays a scripted AI coding agent session — no opencode server, no account, and no API key required.

Is the demo a real AI model answering my questions?

No. The demo is a fixed, offline walkthrough — the same bug-fix example every time, using the app's real UI components (message bubbles, tool call cards, the diff viewer, permission prompts). It is not a live model call and does not talk to any server or API. It exists to show you the interface, not to answer arbitrary coding questions.

What does the demo walkthrough show?

A short bug report ("the login button doesn't respond on Android when the keyboard is open"), the agent's reasoning, a file search tool call, an inline diff proposing the fix, and a permission prompt asking to run the test suite — which you can approve or deny to see both outcomes.

Do I need an internet connection to try the demo?

No. The demo is fully offline and hardcoded into the app — it works in airplane mode. Only connecting to your own real opencode server later requires network access.

Does trying the demo cost anything?

No. OpenCode Mobile is free and open-source, and the demo doesn't call any AI model or API, so there's no usage cost either. Costs only start if and when you connect your own opencode server with your own provider API key.
