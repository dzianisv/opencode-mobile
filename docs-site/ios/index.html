No iOS app — OpenCode Mobile is Android-only

There is no iPhone or iPad app, and none is planned. OpenCode Mobile is Android-only by owner decision (October 2026, GitHub issue #65, closed as not planned). The Android app is live today on Google Play, F-Droid, and as a direct APK.

This page exists so searchers looking for an iOS version get the honest answer instead of a stale progress page.

Why no iOS

A free app pays the Apple Developer fee and the macOS CI cost with no revenue to cover them, and a small team keeps one platform done well instead of two done halfway. The iOS build was closed in October 2026 — it was a decision, not a delay. If that decision ever changes, it will be announced from the repository.

If you have an Android phone (or a spare one), the app works today. See the setup guide or learn how to use opencode on your phone.

Your options right now if you're on iPhone

  • Use an Android device. Even an inexpensive or spare Android phone runs the full app today.
  • Use the opencode web/desktop interface. Since opencode runs as a server you control, you can reach it from a desktop or — unoptimized — from a mobile browser. It isn't a phone-native experience, but it works.
  • Watch the repo. Releases and any future platform news are announced from GitHub.

Frequently asked questions

Is there an OpenCode app for iOS or iPhone?

No. There is no iOS app and none is planned. OpenCode Mobile is Android-only by owner decision (October 2026, GitHub issue #65, closed as not planned).

Can I use OpenCode on my iPhone at all right now?

There's no native iOS app. Because opencode runs as a server you control, you can open its web interface from a mobile browser, but it isn't optimized for phones. Android remains the only supported native option.

Is the Android app free and private?

Yes — free, open source under the MIT license, with no ads and no analytics by default. Your code and API keys stay on your own server. See the privacy policy.
